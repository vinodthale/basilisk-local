## Documentation Guidelines

When adding new documentation:

1. **Guides** - Place technical guides and methodology documentation in `guides/`
2. **Tutorials** - Place step-by-step learning materials in `tutorials/`
3. **Contributing** - Place contribution guidelines in `contributing/`
4. Use clear, descriptive filenames in UPPER_SNAKE_CASE for consistency
5. Include a table of contents for documents longer than 3 sections
6. Cross-reference related documentation with relative links
